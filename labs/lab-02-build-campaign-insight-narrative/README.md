# Lab 2: Build a Campaign Insight Narrative

This folder is self-contained. It includes realistic synthetic Excel data plus Tableau starter and packaged sample files.

Files:

- `lab-02-campaign-story.xlsx` — mock business data, scenario, dictionary, and evidence templates.
- `lab-02-starter.twb` — Tableau starter connected to the Excel file through a relative `Data/` path. If Tableau prompts for the source, select `lab-02-campaign-story.xlsx` in this folder.
- `lab-02-sample.twbx` — packaged Tableau sample with the Excel workbook embedded.

Use the detailed procedure in `LG-Data Storytelling with Tableau.pdf`. The PowerPoint intentionally contains concepts, visual examples, outcomes, and acceptance criteria only.

Acceptance evidence:

- The Tableau workbook opens without a repair warning.
- Field types and analysis grain match the Data Dictionary.
- The required views, dashboard or story answer the stated decision question.
- Filters/actions have visible state and predictable clearing behaviour.
- The learner records one interpretation, one limitation, and the acceptance-check result.
