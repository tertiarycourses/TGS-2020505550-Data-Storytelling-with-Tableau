# Data Storytelling with Tableau

WSQ courseware and hands-on labs for **TGS-2020505550**.

The public repository contains the current course slides, Learner Guide, Lesson Plan, and ten self-contained Tableau labs. Each lab includes realistic mock Excel data and starter Tableau workbook files. Detailed procedures are in the Learner Guide and each lab README; the slide deck remains visual and concept-led.

## Course outcomes

- Use Tableau for data visualisation.
- Identify trends and patterns from data.
- Develop dashboards and stories for data storytelling.
- Present stories to stakeholders and review them with subject-matter experts.
- Design interactive visualisations for data storytelling.

## Repository structure

- `courseware/` — PowerPoint/PDF slides, Learner Guide, and Lesson Plan.
- `labs/` — ten numbered, self-contained lab folders.
- `labs/lab-XX-*/` — realistic Excel data, a starter Tableau workbook, a packaged sample, and lab brief.
